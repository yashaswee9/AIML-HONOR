# Multi-Gateway Payment Processing Engine

## Assignment 1

This project implements a multi-gateway payment processing system using Python and Object-Oriented Programming.

## Supported Payment Gateways

- Razorpay
- Stripe

## Supported Payment Methods

- Card
- UPI

## Project Structure

- `payment_methods.py` - Payment method classes
- `factories.py` - Payment method factories
- `aggregators.py` - Gateway aggregator classes
- `aggregator_factory.py` - Aggregator factory
- `main.py` - CLI application

## How to Run

```bash
python main.py
